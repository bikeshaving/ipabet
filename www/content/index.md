<Callouts/>

IPAbet is an **extended US keyboard**. Unshifted keys type plain US letters, digits, punctuation, and shortcuts, so you can leave it on all day. IPA is typed with <kbd>⇧</kbd> and <kbd>⌥</kbd>: <Combo keys="s ⇧H" out="ʃ"/> <Combo keys="5 ⇧H" out="ə"/> <Combo keys="⌥n n" out="ñ"/>.

<Cards>
<Card title="Works in every app">
Type IPA into Word, Praat, ELAN, LaTeX, Slack or your browser. Works offline.
</Card>
<Card title="Familiar spellings">
sh, th and ng become ʃ, θ and ŋ. Accents are on Option, like the Mac’s own accent keys. Symbols with no Latin letter start from a digit: `5` `⇧H` → ə.
</Card>
<Card title="Capitals stay capitals">
Holding Shift types capitals as usual, so SHIP stays SHIP. Caps Lock turns the changes off, so PATH stays PATH.
</Card>
</Cards>

## Install

**macOS:** run [IPAbet.pkg](/download/macos), or `brew install --cask bikeshaving/tap/ipabet`. Then pick **IPA** in the input menu at the top right of the screen. If it isn't there, log out and back in.

**Windows:** run [IPAbet-x64.msi](/download/windows), or [IPAbet-arm64.msi](/download/windows/arm64) on an ARM PC. Then pick IPAbet in the language bar, or press Win+Space.

**Linux:** download [ipabet-ibus-amd64.deb](/download/linux) ([arm64](/download/linux/arm64)) and run `sudo apt install ./ipabet-ibus-amd64.deb`. Then pick IPAbet in the input menu. If you use fcitx5, get [ipabet-fcitx5](/download/linux/fcitx5) instead.
