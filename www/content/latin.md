IPAbet is an IPA keyboard, but its dead keys put any diacritic on any letter, so it also writes the Latin alphabets of most languages. Everything on this page is generated by typing through the keyboard's own engine, so it only lists what the keyboard really does.

Capitals: hold Shift on the letter, as in <code class="k">⌥e ⇧A</code> for Á. Letters marked † type their capital only with the **Capital Digraphs** option on, from the input menu: <code class="k">⇧A⇧E</code> for Æ.
