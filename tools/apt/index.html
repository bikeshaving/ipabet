Bike Shaving apt repository

Debian and Ubuntu packages, signed. Installing from here means apt upgrade keeps them current.

Install

curl -fsSL https://apt.bikeshaving.org/bikeshaving.gpg | sudo tee /usr/share/keyrings/bikeshaving.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/bikeshaving.gpg] https://apt.bikeshaving.org stable main" | sudo tee /etc/apt/sources.list.d/bikeshaving.list
sudo apt update

Packages

ipabet-ibusIPAbet, the IPA keyboard, for IBus — what GNOME, Ubuntu, and Fedora already run
ipabet-fcitx5the same input method for fcitx5
sudo apt install ipabet-ibus

Then log out and back in, and pick IPAbet from the input menu.
